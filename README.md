# Marine Managed

One source of truth for your boat.

Fill out a profile for your boat (and trailer), then track everything that happens to it:
service and repair history, insurance, storage, costs, and a running list of known issues.

An MCP connector exposes all of that context to Claude, so you can troubleshoot a new
problem with full knowledge of your boat's history, and have Claude write new findings
back into the app.
